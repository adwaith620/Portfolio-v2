# Adwaith Krishna M H — Portfolio

A responsive, editorial portfolio site built with React and Vite. The visual system uses a fluorescent lime loading state and hero, oversized typography, a modular work grid, an experience accordion, and scroll-triggered entrance animations.

## Run locally

```bash
npm install
npm run dev
```

## Customize

Update `src/data.js` to change the profile copy, links, work cards, and experience rows. Project cards use remote image URLs so the repository stays lightweight; swap those URLs for your own hosted assets when ready.

## Build

```bash
npm run build
```
